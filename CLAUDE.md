# Diretrizes Globais do Projeto

## UI, UX e Design System
- Sempre aplique as regras e boas práticas das ferramentas `ui-ux-pro-max` e `impeccable` para qualquer componente visual, layout ou estilo.
- Garanta consistência de design, boas escolhas de cores, espaçamento responsivo e acessibilidade (a11y).

## Qualidade e Padrões de Código
- Refatore a interface mantendo o código limpo e modular.
- Dê preferência por melhorias de micro-interações, tipografia e feedback visual ao usuário.
